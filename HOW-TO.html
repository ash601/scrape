LinkedIn

Scrape

Paste a LinkedIn post link. Get everyone who commented. Download a CSV.

You need
  1. Node.js 20+: nodejs.org (LTS).
  2. An Apify key (free account, $5 free a month): console.apify.com → API & Integrations.
3 steps
  1. Double-click START (START.cmd on Windows, START.command on Mac). First time takes a couple of minutes. Opens http://localhost:3961.
    Mac won't open it? Right-click START.command → Open.
  2. Add your Apify key on the top row. It shows ✓ when it works.
  3. Paste a post link → Get commenters → Download CSV.
Good to know
  1. 100 comments ≈ $0.20. The max box caps each run, so no surprise bills.
  2. Everything stays in my-scrapes/: your key, past scrapes, CSVs.
  3. Turn off (top right) stops it.
